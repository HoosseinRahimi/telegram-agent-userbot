# 🤖 تلگرام یوزربات هوشمند و سیستم ایجنت (Telegram AI Agent Userbot)

یک یوزربات شخصی تلگرام (MTProto Userbot) کاملاً ماژولار، استاندارد، ضد بن و ایمن، پیاده‌سازی‌شده با **Telethon** و متصل به موتور مدل‌های زبانی هوش مصنوعی (**Google Gemini**، **OpenAI** و **Ollama / Local LLMs**).

این سیستم هم‌زمان دو کارکرد حیاتی را پوشش می‌دهد:
1. **خلاصه‌سازی و مانیتورینگ هوشمند کانال‌ها و چت‌ها (Summarization & Digest):** در دو حالت دستوری (با ارسال فرمان در Saved Messages) و زمان‌بندی خودکار دوره‌ای.
2. **پاسخ‌گویی هوشمند به پیام‌های خصوصی (Human-like DM Auto-reply):** با شبیه‌سازی کامل رفتارهای انسانی (وضعیت `Typing...` متناسب با طول پاسخ و تاخیر تصادفی Jitter)، مکانیزم تجمیع پیام‌ها (**ChatDebouncer**)، کول‌داون حضور انسان، درک پیام‌های ریپلای‌شده، و لایه‌های سخت‌گیرانه فیلترینگ و ضد بن (Anti-Ban).

## 🚀 راهنمای راه‌اندازی گام‌به‌گام

### گام ۱: دریافت اعتبارسنجی API تلگرام
1. به سایت رسمی تلگرام به آدرس [my.telegram.org](https://my.telegram.org) مراجعه کنید.
2. با شماره تلفن همراه اکانت خود وارد شده و کد ارسال‌شده در تلگرام را ثبت کنید.
3. به بخش **API development tools** بروید.
4. فرم ساخت اپلیکیشن را با عنوان دلخواه پر کنید تا دو شناسه به شما داده شود:
   - `TELEGRAM_API_ID` (یک عدد چندرقمی)
   - `TELEGRAM_API_HASH` (یک رشته شامل حروف و اعداد)

### گام ۲: تنظیم متغیرهای محیطی (`.env`)
فایل `.env.example` را کپی کرده و نام آن را به `.env` تغییر دهید:
```bash
cp .env.example .env
```
سپس مقادیر کلیدی را در آن وارد نمایید:
```env
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=your_telegram_api_hash_here

# انتخاب مدل زبانی: gemini یا openai یا mock
LLM_PROVIDER=gemini
GEMINI_API_KEY=your_google_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash

# کانال‌های مورد نظر برای خلاصه‌سازی خودکار (جداشده با کاما)
DIGEST_CHANNELS=durov,tech_news_channel

# بازه زمانی خلاصه‌سازی خودکار (دقیقه)
DIGEST_INTERVAL_MINUTES=360
```

### گام ۳: شخصی‌سازی لحن و پرسونا (`persona_prompt.txt`)
فایل `persona_prompt.txt` به شما امکان می‌دهد بدون دست زدن به کدهای برنامه، نحوه معرفی، لحن گفتگو (رسمی یا صمیمی)، و اطلاعات لازم را به هوش مصنوعی آموزش دهید.

### گام ۴: اجرای برنامه

#### روش مستقیم با پایتون:
```bash
python main.py
```
> **نکته در اولین اجرا:** در اجرای اول، کلاینت در خط فرمان از شما شماره تلفن و کد تأیید ارسالی تلگرام را می‌خواهد. پس از وارد کردن، نشست در فایل `userbot_session.session` ذخیره شده و در دفعات بعد لاگین کاملاً خودکار انجام خواهد شد.

#### روش اجرا با Docker Compose:
```bash
docker-compose up -d
```

#### دیپلوی ابری (Railway / Render / Fly.io):
برای محیط‌های بدون دیسک پایدار، ابتدا اسکریپت ساخت سشن استرینگ را اجرا کنید:
```bash
python scripts/generate_session_string.py
```
سپس رشته تولیدشده را در متغیر محیطی `TELEGRAM_SESSION_STRING` در پنل سرور ابری خود قرار دهید.

## 🎮 فرامین کنترلی در پیام‌های ذخیره‌شده (Saved Messages)

می‌توانید مستقیماً در چت **Saved Messages** خودتان دستورات زیر را ارسال کنید:

| دستور | توضیح | مثال |
|---|---|---|
| `/summary <channel> [limit] [topic]` | اسکن و خلاصه‌سازی تحلیلی فوری پیام‌های اخیر یک کانال | `/summary @durov 30 اخبار هوش مصنوعی` |
| `/digest [limit]` | استخراج و تولید بولتن خبری از تمام کانال‌های منتخب | `/digest 20` |
| `/pause [minutes]` | توقف موقت پاسخ‌دهی خودکار (با تعیین زمان یا نامحدود) | `/pause 30` |
| `/resume` | فعال‌سازی مجدد پاسخ‌دهی خودکار | `/resume` |
| `/mode <gemini\|openai\|mock>` | تغییر آنلاین و آنی موتور هوش مصنوعی فعال | `/mode openai` |
| `/blacklist <add\|remove> <user>` | افزودن یا حذف کاربر/شناسه از لیست سیاه بدون ری‌استارت | `/blacklist add @spammer` |
| `/status` | مشاهده وضعیت برخط، موتور هوش مصنوعی، وضعیت توقف و مانیتورینگ | `/status` |
| `/help` | نمایش راهنمای کامل فرامین | `/help` |

## 🛡️ تدابیر ایمنی و لایه‌های ضد بن (Anti-Ban & Safety)

1. **مدیریت خطای FloodWait (`@with_floodwait`):** در صورت دریافت هرگونه خطای Rate limit از سوی تلگرام، دکوراتور اختصاصی زمان اعلام‌شده توسط تلگرام را همراه با Jitter تصادفی دریافت کرده و فرآیند را با ایمنی کامل مجدداً اجرا می‌کند.
2. **تجمیع پیام‌ها با ChatDebouncer:** جلوگیری از ارسال پاسخ‌های موازی و تکراری در زمانی که مخاطب چند پیام پشت سر هم ارسال می‌کند.
3. **کول‌داون حضور انسان (Active Chat Cooldown):** اگر خود شما اخیراً در یک پیوی پیامی ارسال کرده باشید، بات تا ۵ دقیقه پاسخ خودکار نخواهد داد تا در گفتگوی زنده شما مداخله‌ای نشود.
4. **رفتار شبه‌انسانی (Humanizer):**
   - محاسبه زمان خواندن متناسب با طول پیام ورودی.
   - ارسال اکشن `Typing...` در تلگرام پیش از ارسال پیام.
   - اعمال تاخیر تایپ متناسب با طول پاسخ هوش مصنوعی.
5. **فیلترهای چندلایه امنیتی و نرمال‌سازی فارسی:**
   - نرمال‌سازی کامل کاراکترهای عربی/فارسی (`ي/ی`, `ك/ک`) و حذف نیم‌فاصله‌ها (`\u200c`) و اعراب جهت جلوگیری از دور زدن فیلتر حساسیت.
   - نادیده گرفتن قطعی اکانت‌های رسمی تلگرام (`777000`).
   - مسدودسازی خودکار ربات‌ها (`is_bot=True` و پسوند `bot`).
   - توقف فوری پاسخ‌دهی و ارسال آلارم اضطراری به Saved Messages در صورت شناسایی پیام‌های حاوی رمز عبور، کد تایید یا اطلاعات بانکی.

## 🧪 اجرای آزمون‌های خودکار (Offline Verification)

تمام اجزای یوزربات مجهز به یک زیرساخت تست ۱۰۰٪ آفلاین هستند که بدون نیاز به اتصال به تلگرام یا مصرف سهمیه API اجرا می‌شوند:

```bash
python -m pytest tests/ -v
```

پوشش آزمون‌ها شامل **۵۹ تست جامع** در ۶ سطح است:
- **Tier 1 (Feature Tests):** ۲۹ تست پوشش تمامی ماژول‌ها و توابع پایه.
- **Tier 2 (Boundary Tests):** ۷ تست ورودی‌های مرزی، طول‌های پیام بزرگ و یونیکد فارسی.
- **Tier 3 (Combination Tests):** ۵ تست تعامل متقابل فیلترها و مقاومت در برابر قطعی LLM یا خطای Flood.
- **Tier 4 (Scenarios Tests):** ۴ تست سناریوهای واقعی کاربر و حملات فیشینگ.
- **Tier 5 (Adversarial Tests):** ۵ تست آزمون استرس و پیام‌های هم‌زمان.
- **Tier 6 (Enhancements Tests):** ۹ تست برای دیبانسر، کول‌داون حضور انسان، نرمال‌سازی فارسی و فرامین جدید.
